# رياضيات ثالث متوسط – الفصل الدراسي الأول (تطبيق ويب يعمل دون إنترنت)

تطبيق ويب تقدّمي (PWA) يغطي الفصول الخمسة: المعادلات الخطية، العلاقات والدوال الخطية، الدوال الخطية، المتباينات الخطية، أنظمة المعادلات الخطية.
يتضمن عروض شرائح لكل درس، شرحًا وأمثلة، «تحقق من فهمك»، تمارين محلولة، مسائل «من واقع الحياة»، أسئلة تقويمية، ملخصات وبطاقات،
ومراجعات واختبارات (7 نماذج) للفصلين 1و2، و3و4، ومراجعة واختبارًا شاملين.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `math3`).
2. ارفع **محتويات هذا المجلد** (وليس المجلد نفسه) إلى جذر المستودع، بما فيها الملفات المخفية `.nojekyll`.
   - من الموقع: Add file ← Upload files ← اسحب الملفات والمجلد `assets` ← Commit.
   - أو من سطر الأوامر:
     ```bash
     git init && git add -A && git commit -m "first version"
     git branch -M main
     git remote add origin https://github.com/USERNAME/math3.git
     git push -u origin main
     ```
3. من إعدادات المستودع: Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` و `/ (root)` ← Save.
4. بعد دقيقة تقريبًا يصبح الموقع متاحًا على: `https://USERNAME.github.io/math3/`

> جميع المسارات نسبية، فيعمل التطبيق من أي مسار فرعي على GitHub Pages.

## التثبيت على سطح المكتب
- افتح الموقع في Chrome أو Edge ← اضغط زر «📥 تثبيت التطبيق» في أعلى الصفحة، أو أيقونة التثبيت في شريط العنوان.
- على الجوال: قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».

## العمل دون إنترنت (الأولوية للكاش)
- عند أول زيارة يحفظ عامل الخدمة `sw.js` جميع الصفحات والخطوط والأيقونات.
- كل الطلبات تُخدم من الكاش أولًا (Cache-First)، ولا يُستعمل الإنترنت إلا لملف غير محفوظ.
- الخطوط محلية داخل `assets/fonts` (لا اعتماد على خدمات خارجية).

## تحديث المحتوى
عند رفع نسخة جديدة يتغير رقم الإصدار داخل `sw.js` تلقائيًّا (بصمة المحتوى)، فيظهر للمستخدم تنبيه «يتوفر تحديث جديد» مع زر «تحديث الآن».
